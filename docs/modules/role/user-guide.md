# Role & Permission – Hướng dẫn người dùng (Admin)

## Ai dùng module này?

Chỉ tài khoản có quyền quản lý vai trò (thường là **Admin**).

## Xem danh sách vai trò

1. Đăng nhập Admin  
2. Sidebar → **Phân quyền**  
3. Tìm kiếm theo tên hoặc mô tả vai trò  

## Tạo vai trò mới

1. Nhấn **Thêm vai trò**  
2. Nhập tên và mô tả (tuỳ chọn)  
3. Chọn ít nhất **một quyền** theo từng nhóm module  
4. Nhấn **Lưu**  

Sau khi tạo, vào **Người dùng** để gán vai trò mới cho nhân viên.

## Sửa vai trò

1. Nhấn biểu tượng bút ở dòng vai trò cần sửa  
2. Cập nhật mô tả hoặc bộ quyền  
3. Lưu  

**Lưu ý:** Vai trò **Hệ thống** (Admin, Manager, Staff) không đổi được tên.

## Xóa vai trò

Chỉ xóa được vai trò **Tùy chỉnh** và **chưa gán cho ai**. Nếu còn người dùng, hệ thống báo lỗi — hãy chuyển user sang vai trò khác trước.

## Vai trò hệ thống

| Vai trò | Mô tả |
|---------|--------|
| Admin | Toàn quyền hệ thống |
| Manager | Quyền vận hành (theo seed) |
| Staff | Quyền hạn chế (theo seed) |

Không xóa hoặc đổi tên các vai trò này.
