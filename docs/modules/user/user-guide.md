# User – Hướng dẫn người dùng (Admin)

## Ai dùng module này?

Chỉ tài khoản có quyền quản lý người dùng (thường là **Admin**).

## Xem danh sách

1. Đăng nhập Admin  
2. Sidebar → **Người dùng**  
3. Tìm kiếm theo email/họ tên, lọc trạng thái hoặc vai trò  

## Tạo người dùng

1. Nhấn **Tạo người dùng**  
2. Nhập email, họ tên, mật khẩu tạm, chọn vai trò  
3. Lưu → gửi thông tin đăng nhập cho nhân viên (thủ công)  

## Cập nhật

Mở chi tiết → sửa họ tên / vai trò / ảnh đại diện (nếu có).

## Vô hiệu hóa / kích hoạt

- **Vô hiệu hóa:** user không đăng nhập được  
- **Kích hoạt:** cho phép đăng nhập lại  

Không thể vô hiệu hóa chính tài khoản đang đăng nhập.

## Mở khóa

Khi user bị khóa do đăng nhập sai nhiều lần → Admin chọn **Mở khóa**.

## Reset mật khẩu

1. Chi tiết user → **Reset mật khẩu**  
2. Nhập mật khẩu mới  
3. User phải đăng nhập lại bằng mật khẩu mới  

## Xóa (vô hiệu hóa)

Trong MVP, xóa = vô hiệu hóa tài khoản (giữ dữ liệu lịch sử).
