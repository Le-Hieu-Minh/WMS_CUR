# Auth – Hướng dẫn người dùng

## Đăng nhập

1. Mở hệ thống WMS → trang Đăng nhập  
2. Nhập email và mật khẩu do Admin cấp  
3. Nhấn **Đăng nhập**  

Tài khoản mặc định (môi trường dev): `admin@wms.com` / `Admin@123`

## Lỗi thường gặp

| Thông báo | Cách xử lý |
|-----------|------------|
| Email hoặc mật khẩu không đúng | Kiểm tra lại thông tin |
| Tài khoản đã bị vô hiệu hóa | Liên hệ Admin |
| Tài khoản tạm khóa | Đợi ~15 phút hoặc nhờ Admin mở khóa |
| Tự về trang login | Phiên hết hạn → đăng nhập lại |

## Đăng xuất

Nhấn icon **Đăng xuất** góc phải Header.

## Đổi mật khẩu

1. Header → **Đổi MK** (hoặc `/change-password`)  
2. Nhập mật khẩu hiện tại + mật khẩu mới (≥8 ký tự, có hoa, thường, số)  
3. Lưu → hệ thống yêu cầu đăng nhập lại
